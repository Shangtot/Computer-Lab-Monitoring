# User guide

## Admin dashboard

Use the admin account to sign in and review the monitoring overview.

- Default admin username: `admin`
- Default admin password: `Admin123!`
- Default viewer username: `viewer`
- Default viewer password: `Viewer123!`

## Role behavior

- Admin can review data and submit monitoring events.
- Viewer has read-only dashboard access.

## Privacy rules

- Only domain names are recorded by the browser extension.
- No passwords or page content are stored.
- Only school-authorized lab computers should run the system.
